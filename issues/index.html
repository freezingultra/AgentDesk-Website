Blogs / release notes

V35

Why the streaming duplicate happened

AgentDesk streams provider deltas into the UI. The bug came from sending the assembled response again after streaming finished. The fix keeps one copy of the streamed text.

Why there is a public source snapshot

The development repository stays private while the website publishes a read-only source snapshot for visitors who want to inspect the application.

AgentDesk web research

Local agent tools

AgentDesk includes memory, file reading, workspace tools and optional terminal execution, with tool activity surfaced in the chat UI.

When reporting a new problem, include the AgentDesk version, provider/model, steps to reproduce and relevant error text. Never post API keys, passwords or other secrets.
